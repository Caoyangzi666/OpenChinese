# OpenChinese v0.1.4-alpha

An offline Android reader for Chinese EPUBs with adaptive pinyin and personal flashcards. Requires Android 8.0+ and an up-to-date Android System WebView.

## Included

- Configurable word press: 0.3 / 0.4 / 0.5 / 0.7 / 1 second; **0.4 seconds is the default**.
- Persistent dark mode for the app, dictionary and book pages.
- Horizontal page swipes, side taps, chapter navigation and reading-position restoration.
- Independent word segmentation with adaptive HSK pinyin and identified supplemental/estimated classifications.
- Flashcard notes, review scheduling and JSON backup/import.
- Confirmed deletion of imported books, preserving saved cards and original EPUB files.
- Included offline CC-CEDICT dictionary and separate HSK vocabularies.

## Install or update

Download `OpenChinese-v0.1.4-alpha.apk` and open it on Android. Export a flashcard backup first. Install as an update over the official alpha app; uninstalling or clearing app storage removes private data. Community builds signed with another key cannot update it in place.

## Alpha limitations

HSK coverage, ambiguous segmentation and polyphonic readings still need feedback. No DRM, fixed-layout fidelity, vertical Chinese layout, audio or cloud sync is provided. Desktop/browser regression checks and APK integrity/signature checks pass; the v0.1.4 changes still require confirmation on an Android device.

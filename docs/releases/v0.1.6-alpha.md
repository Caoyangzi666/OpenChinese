# OpenChinese v0.1.6-alpha

This alpha fixes slow or apparently stuck chapter opening and pinyin syllables split across lines. It preserves word-based HSK filtering and personal flashcards. Requires Android 8.0+ and an up-to-date Android System WebView.

## Fixes

- Prepare only the active EPUB chapter. Some EPUBs contain almost a full novel in one spine item; these are displayed in bounded sections instead of generating the whole chapter DOM before showing text.
- Page turns cross sections automatically in both directions. The original chapter list remains intact. Only the next section of the current chapter may be prefetched, with a bounded in-memory cache for recent sections.
- Read chapter files on a background thread and yield during text preparation. Back and switching chapters cancel obsolete work; delayed callbacks cannot overwrite the new selection.
- Show a retry option for missing/unreadable chapters instead of permanent Loading, with a preparation timeout as a final recovery path.
- Keep every pinyin syllable intact despite publisher break-all styles. Words may wrap between syllables while remaining one word for HSK classification, dictionary lookup and flashcards.
- Preserve source-character reading anchors, including a word split across pages; migrate previous whole-chapter token bookmarks.
- Retain original red publisher note markers, note content and inline emphasis. No replacement or removal of those notes is applied.

## Preserved

Whole-word HSK thresholds, unknown-word pinyin, Simplified/Traditional matching, dictionary pronunciation selection, flashcard notes/review/JSON backup, 0.4-second default hold, swipe and side-tap navigation, dark mode and book deletion with flashcards retained. No account, ads, analytics or Android INTERNET permission.

## Install or update

Download **OpenChinese-v0.1.6-alpha.apk** below. Install over the existing official app without uninstalling or clearing storage, so private books and cards remain available. Export a flashcard backup first. The official alpha signing key is unchanged. The source archive is the complete corresponding source, including the offline data, tests and build scripts.

## Validation

Passed: 19 existing engine regression groups, an additional cooperative-engine suite and six browser suites (interface, native-bridge simulation, gestures, preferences, word reading and chapter loading). The original 9,094-character Mockingbird chapter and 74,932-character To Live section were checked locally with the browser throttled to simulate 4x slower CPU. Pinyin annotations were checked at 320/412-pixel widths with 32-pixel text. Original publisher note images remain present.

APK integrity, source-asset equality, alignment, version code 7 and v2/v3 signatures were verified. **This release has not yet been verified on a physical Android device or emulator.** Desktop timings are not device guarantees. Follow TEST-ON-ANDROID.txt before relying on the update for a long reading session.
